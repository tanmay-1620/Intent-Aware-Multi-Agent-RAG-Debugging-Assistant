FastAPI is a modern, fast (high-performance), web framework for building APIs with Python based
on standard Python type hints.

The key features are:

¢ Fast: Very high performance, on par with NodeJS and Go (thanks to Starlette and Pydantic).
One of the fastest Python frameworks available.

¢ Fast to code: Increase the speed to develop features by about 200% to 300%. *
e Fewer bugs: Reduce about 40% of human (developer) induced errors. *
¢ Easy: Designed to be easy to use and learn. Less time reading docs.

¢ Short: Minimize code duplication. Multiple features from each parameter declaration
bugs.

¢ Robust: Get production-ready code. With automatic interactive documentation.

group of optional dependencies:

Used by Pydantic:
* email-validator © - for email validation.
Used by Starlette:

¢ httpx @- Required if you want to use the TestClient .
¢ jinja2 @ - Required if you want to use the default template configuration.

* python-multipart  - Required if you want to support form ‘parsing”, with request. form() .

Used by FastAPI:

* uvicorn (%- for the server that loads and serves your application. This includes
uvicorn[standard] , which includes some dependencies (e.g. uvloop ) needed for high
performance serving.

¢ fastapi-clilstandard] -to provide the fastapi command.

e This includes fastapi-cloud-cli , which allows you to deploy your FastAPI application to

Without standard Dependencies

If you don't want to include the standard optional dependencies, you can install with

Without fastapi-cloud-cli

If you want to install FastAPI with the standard dependencies but without the fastapi-cloud-cli,
you can install with pip install "fastapi[standard-no-fastapi-cloud-cli]".
